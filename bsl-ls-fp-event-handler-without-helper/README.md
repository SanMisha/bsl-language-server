# EventHandlerInvalidSignature без синтакс-помощника

Без синтакс-помощника платформы диагностика `EventHandlerInvalidSignature` помечает ошибкой правильный обработчик события элемента формы. Здесь — минимальный пример и скрипт, который это показывает.

## Что внутри

- `src/` — конфигурация из тестовых ресурсов BSL LS (`src/test/resources/metadata/formDecorationEvents`): обработка `Обработка1` с управляемой формой `Форма`. Отличия от исходной: в `Form.xml` у декорации-надписи `Гиперссылка` добавлено событие `URLProcessing`, а модуль формы переписан — удалён `ЗабытыйМетод`, добавлен обработчик `URLProcessing`, оба обработчика помещены в область `ОбработчикиСобытийЭлементовШапкиФормы`. Обработчики:
  - `ГиперссылкаНажатие(Элемент)` — событие `Click`;
  - `ГиперссылкаОбработкаНавигационнойСсылки(Элемент, НавигационнаяСсылкаФорматированнойСтроки, СтандартнаяОбработка)` — событие `URLProcessing`.

  Обе сигнатуры совпадают с синтакс-помощником.
- `cfg/no-helper.json` — `{"v8platform": {"enabled": false}}`. С ним сервер не загружает синтакс-помощник, даже если 1С установлена.
- `run.sh` — запускает `analyze` и печатает замечания `EventHandlerInvalidSignature`.

## Запуск

Нужны Java 21+, jq и bash (Linux или macOS).

    ./run.sh <путь к bsl-language-server-1.1.0-rc.9-exec.jar>

Если установлена платформа 1С, вторым аргументом можно передать каталог, где лежит `shcntx_ru.hbk`, — скрипт добавит прогон с синтакс-помощником:

    ./run.sh <путь к jar> /opt/1cv8/8.5.1.1343

Полные отчёты и логи — в `out/no-helper/` и `out/with-helper/`. Без bash прогон без синтакс-помощника запускается так:

    java -jar <путь к jar> analyze --srcDir src --configuration cfg/no-helper.json --outputDir out/no-helper --reporter json

## Что ожидается

Замечаний `EventHandlerInvalidSignature` нет: обе сигнатуры верные.

## Что получается на 1.1.0-rc.9

    == Без синтакс-помощника (v8platform.enabled = false)
    строка 8: EventHandlerInvalidSignature — Сигнатура обработчика "ГиперссылкаОбработкаНавигационнойСсылки" не совпадает с контрактом события платформы: ожидается до 1 параметров, объявлено 3
    == С синтакс-помощником (/opt/1cv8/8.5.1.1343)
    Loaded 2542 platform contexts from 1C syntax helper
    замечаний EventHandlerInvalidSignature нет

Проверено на macOS (Apple Silicon) и Ubuntu 24.04 на aarch64, OpenJDK 21, платформа 8.5.1.1343. На Linux путь к синтакс-помощнику другой — `/opt/1cv8/arm64/8.5.1.1343`, остальной вывод тот же.

## Контрольные проверки

Исправление не должно менять эти замечания. Для проверки — изменить объявление `ГиперссылкаНажатие` в модуле формы и запустить `run.sh` с каталогом платформы.

- `ГиперссылкаНажатие()` без параметров — строка 4, «ожидается до 1 параметров, объявлено 0», без синтакс-помощника и с ним. Можно ли объявлять меньше параметров, чем передаёт платформа, обсуждается в #4572.
- `ГиперссылкаНажатие(Элемент, ЛишнийПараметр)` с синтакс-помощником — строка 4, «ожидается до 1 параметров, объявлено 2».

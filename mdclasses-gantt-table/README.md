# Таблица поля диаграммы Ганта не попадает в элементы формы

Конфигуратор выгружает таблицу поля диаграммы Ганта прямо внутрь `<GanttChartField>`, без `<ChildItems>`. mdclasses 0.21.0 такую таблицу не читает: в `getElements()` и `getPlainElements()` нет ни её, ни её колонок, ни их событий. BSL Language Server берёт обработчики событий формы из `getPlainElements()`, поэтому обработчики таблицы и колонок получают ложное замечание `UnusedLocalMethod`.

## Что внутри

- `src/` — конфигурация с обработкой `Обработка1` и управляемой формой `Форма`. Каркас взят из тестовых ресурсов BSL LS (`src/test/resources/metadata/formDecorationEvents`), `Form.xml` и модуль формы написаны заново. В `Form.xml` `<Table>` лежит прямо в `<GanttChartField>`, как в выгрузке конфигуратора:
  - поле ввода `Поле`, событие `OnChange` → `ПолеПриИзменении`;
  - поле диаграммы Ганта `Диаграмма`, в нём таблица `ДиаграммаТаблица`, событие `OnActivateRow` → `ДиаграммаТаблицаПриАктивизацииСтроки`;
  - колонка таблицы `ДиаграммаТаблицаТекст`, событие `OnChange` → `ДиаграммаТаблицаТекстПриИзменении`.
- `control/` — та же конфигурация, но `<Table>` обёрнут в `<ChildItems>`. Модуль формы тот же.
- `probe/FormProbe.java` — вызывает mdclasses напрямую и печатает элементы формы: дерево `getElements()`, плоский `getPlainElements()` с событиями и есть ли там таблица и колонка.
- `run.sh` — запускает пробник и `analyze` BSL LS по обоим каталогам и печатает итог.

Обработчик `ДиаграммаТаблицаПриАктивизацииСтроки` нарочно лежит в области `ОбработчикиСобытийЭлементовШапкиФормы`. Если сервер видит таблицу, на нём появляется замечание `EventHandlerOutsideEventRegion` с областью `ОбработчикиСобытийЭлементовТаблицыФормыДиаграммаТаблица`. Обработчик колонки лежит в правильной области таблицы.

## Запуск

Нужны JDK 21+ (`java`, `javac`, `jar`), `jq` и bash (Linux или macOS). mdclasses и её зависимости скрипт берёт из jar-а BSL LS.

    ./run.sh <путь к bsl-language-server-1.1.0-rc.9-exec.jar>

Код выхода: 0 — ошибка не воспроизвелась, 1 — воспроизвелась, 2 — сбой. Логи и отчёты — в `out/`.

Проверить сборку mdclasses с исправлением можно так: jar из `MDCLASSES_JAR` подкладывается перед mdclasses из jar-а BSL LS и для пробника, и для `analyze`.

    MDCLASSES_JAR=<путь к mdclasses-*.jar> ./run.sh <путь к jar BSL LS>

Без bash `analyze` запускается так:

    java -jar <путь к jar BSL LS> analyze --srcDir src --outputDir out/analyze-src --reporter json

## Что ожидается

В `src/` элементы формы читаются так же, как в `control/`: 14 элементов, у трёх есть события. BSL LS выдаёт на `src/` то же, что на `control/`: одно замечание `EventHandlerOutsideEventRegion` на строке 8, `UnusedLocalMethod` нет.

## Что получается на 1.1.0-rc.9 (mdclasses 0.21.0)

Вывод `run.sh` без дерева элементов:

    == mdclasses, src/
      getPlainElements(): 7 элементов, события есть у 1
      ДиаграммаТаблица в getPlainElements(): НЕТ
      ДиаграммаТаблицаТекст в getPlainElements(): НЕТ
      Итог: mdclasses потеряла элементы ДиаграммаТаблица, ДиаграммаТаблицаТекст

    == mdclasses, control/
      getPlainElements(): 14 элементов, события есть у 3
      Итог: все элементы на месте

    == BSL LS analyze, src/
      строка 8: UnusedLocalMethod — Метод "ДиаграммаТаблицаПриАктивизацииСтроки" не вызывается в теле модуля
      строка 16: UnusedLocalMethod — Метод "ДиаграммаТаблицаТекстПриИзменении" не вызывается в теле модуля

    == BSL LS analyze, control/
      строка 8: EventHandlerOutsideEventRegion — Метод "ДиаграммаТаблицаПриАктивизацииСтроки" — обработчик события и должен находиться в стандартной области «ОбработчикиСобытийЭлементовТаблицыФормыДиаграммаТаблица»

    Итог: ошибка воспроизводится — в src/ mdclasses не отдаёт таблицу поля диаграммы Ганта и её колонку, BSL LS выдаёт UnusedLocalMethod: 2

В `src/` пропадают 7 элементов: таблица, её контекстное меню, командная панель и расширенная подсказка, колонка, её контекстное меню и подсказка.

Проверено на macOS (Apple Silicon), OpenJDK 21.0.11. Результат не зависит от справки платформы: с `{"v8platform": {"enabled": false}}` замечания те же.
